# アニメーション連携

スライドに設定したクリック時のアニメーションを、読み上げのタイミングに合わせて自動で再生できます。ノートの、アニメーションを再生したい位置に `<next>` と書きます。

```
最初の説明です。
<next>
ここでアニメーションが出ます。
```

「最初の説明です」を読み終えたところで1つ目のクリックアニメーションが再生され、続けて次の文を読み上げます。

文の途中にも書けます。

```
ここで<next>アニメーションが出ます。
```

文の途中に書いた場合は、文字数の比率から再生のタイミングを推定します。正確なタイミングにしたい場合は、文の境界（改行の位置）に書いてください。

## `<next>` とアニメーションの数が合わない場合

- **アニメーションの方が多い場合:** 余ったアニメーションは「未指定アニメを自動再生」がオンなら、読み上げが終わった後に設定した間隔（秒）で順に再生されます。オフにすると、クリック待ちのまま残ります
- **`<next>` の方が多い場合:** 余った `<next>` は無視されます
- **`<next>` を1つも書かない場合:** すべてのアニメーションが余りとして扱われます（元のアニメーションは消えません）

GUI の「<next>確認」ボタンを押すと、スライドごとのアニメーションの数と `<next>` の数を一覧で確認できます。

字幕を表示しない設定でも、`<next>` によるアニメーションの再生は同じように動作します。
