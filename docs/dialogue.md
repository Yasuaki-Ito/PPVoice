# 掛け合い（複数の話者）

1枚のスライドのノートの中で話者を切り替えて、掛け合いのナレーションを作れます。

```
<speaker=ずんだもん>今日はリスト構造について説明するのだ。
<speaker=めたん>リスト構造って何かしら？
<speaker=ずんだもん>データを順番に並べたものなのだ。
```

## 役（キャスト）

話者ごとの設定を **役** と呼びます。役には、話者・スタイル（声）、速度・ピッチ・抑揚・音量、字幕の色、字幕に出す名前を設定できます。

役は「音声」タブの **キャスト** で編集します。左に役の一覧、右に選んだ役の設定が表示されます。

| ボタン | 説明 |
|---|---|
| + 追加 | 新しい役を作ります。話者は一覧の次の話者、字幕色は見分けやすい色が順に割り当てられます |
| 複製 | 選んだ役をコピーします（同じ話者でスタイルだけ違う役を作るときなど） |
| 削除 | 選んだ役を削除します。削除した役の文は既定の役が読みます |
| 既定に | 選んだ役を **既定の役** にします |

- **既定の役** は、`<speaker>` を書いていない文と、各スライドの最初の文を読む役です。役を1つしか使わない場合は、今までどおりその役がすべてを読みます
- 一覧には、入力ファイルのノートで各役が読む文の数が表示されます
- ノートに書かれているのに定義されていない役は「⚠ 名前 (未定義)」と表示されます。「追加」で定義できます
- 各行の ▶ で、その役の声を確認できます
- **役名** は、ノートの `<speaker=...>` に書く名前です。初期値は話者名です。「タグをコピー」で `<speaker=役名>` をコピーできます
- 役名を変えても、ノートの `<speaker=...>` は書き換わりません（PPVoice は入力の PPTX を変更しません）

## 話者の切り替え: `<speaker=役名>`

- `<speaker=...>` を書くと、次の `<speaker=...>` までその役が読みます
- 行の途中に書いた場合は、その位置で文が区切られます
- スライドの最初は、既定の役に戻ります（一部のスライドだけを生成しても結果が変わらないように）
- 定義されていない役名は、警告を出して既定の役で読みます

```
<speaker=めたん>ここまでの説明はわかったかしら？<speaker=ずんだもん>ばっちりなのだ。
```

## スタイルの切り替え: `<style=スタイル名>`（VOICEVOX のみ）

その文だけ、役の話者の別のスタイル（感情）で読みます。役（字幕の色・名前）は変わりません。

```
<speaker=ずんだもん>今日はいい天気なのだ。
<style=ささやき>ここだけの話なのだ。
それでは続けるのだ。
```

- スタイル名は、その役の話者が持つスタイルの名前です。見つからない場合は警告を出して、役のスタイルで読みます
- OpenAI互換のエンジン（Kokoro など）にはスタイルがないため、警告を出して無視します
- 字幕の色や名前も変えたい場合は、キャストの「複製」で別の役を作ります

## 間（話者交代）

「音声」タブの **間 (秒)** の「話者交代」で、話者が替わるときの間を、文の区切りとは別に設定できます。空欄なら「文」と同じ長さです。掛け合いのテンポを上げたいときは短めにします。

## 字幕

- 役の **字幕色** を設定すると、その役の字幕がその色になります（ノートの `<color>` タグはさらに優先されます）。「既定」のままなら、字幕タブの文字色です
- 字幕タブの **話者名を表示する** をオンにすると、字幕の前に `名前: ` が太字で付きます。名前は役の **字幕の名前**（空なら役名）です

## テスト再生

「テスト」欄にも `<speaker=...>` を書けば、掛け合いをそのまま試せます。`<speaker>` のない行は既定の役が読みます（一覧で選んでいる役ではありません）。

## クレジット表記

VOICEVOX の音声を使った動画などには、キャラクターごとにクレジット表記（「VOICEVOX:ずんだもん」など）が必要です。生成の最後に、使った話者のクレジット表記がログに表示されます。利用規約はキャラクターごとに異なるので、[VOICEVOX 公式サイト](https://voicevox.hiroshiba.jp/) で確認してください。

## 役の保存

役は、[設定の保存](config.md) の `<cast ...>` タグとして保存されます。既定の役は `<config>` の話者として保存されます。

```
<config speaker=四国めたん style=ノーマル role=めたん turn_pause=0.3>
<cast ずんだもん speaker=ずんだもん style=ノーマル color=#A6E22E>
```
