# よくある質問

## 「話者取得」で「接続できませんでした」と表示される

音声合成エンジンが起動しているか、URL が正しいかを確認してください。

- VOICEVOX の初期設定の URL は `http://localhost:50021` です
- OpenAI互換のサーバでは、URL に `/v1` まで含めます（例: `http://localhost:8880/v1`）

接続できない場合は5秒で、接続後に応答がない場合は30秒で打ち切ります。

## Kokoro-FastAPI などのサーバの導入方法を教えてほしい

サーバの導入・動作は、PPVoice のサポート対象外です。各プロジェクトの案内を参照してください。→ [音声合成エンジン](engines.md#openai-互換エンジン)

## 字幕が長すぎる

ノートを改行で区切ると、字幕も改行ごとに切り替わります。英語のように改行なしの段落で書いている場合は、「文末 (. ! ?) でも区切る」をオンにしてください。字幕の中だけで改行したい場合は `<br>` を使います。

## 読み方がおかしい

`{表示|読み}` で読みを指定できます。VOICEVOX では、アクセント（音の高低）も `{橋|はし|2}` のように指定できます。→ [ノートの書き方](notes.md#読み指定)

## 数式が LaTeX の文字列のまま表示される

LaTeX の変換に失敗しています。生成時のログに警告と失敗した式が表示されるので、式の書き方を確認してください。数式は `{$...$|読み}` の形で、読みと一緒に書く必要があります。

## アニメーションのタイミングがずれる

文の途中に書いた `<next>` は、文字数の比率からタイミングを推定するため、少しずれることがあります。正確に合わせたい場合は、`<next>` を文の境界（改行の位置）に書いてください。→ [アニメーション連携](animation.md)

## 一部のスライドだけ作り直したい

ファイル設定の「スライド」で「一部」を選ぶと、生成するスライドを選べます。

## 不具合を見つけた

[GitHub の Issues](https://github.com/Yasuaki-Ito/PPVoice/issues) で報告してください。PPVoice のバージョン、発生した現象、再現手順（できれば問題が起きる PPTX のノートの内容）を書いていただけると調査が早くなります。
