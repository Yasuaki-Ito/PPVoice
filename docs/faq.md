# よくある質問

## 「話者取得」で「接続できませんでした」と表示される

音声合成エンジンが起動しているか、URL が正しいかを確認してください。

- VOICEVOX の初期設定の URL は `http://localhost:50021` です
- OpenAI互換のサーバでは、URL に `/v1` まで含めます（例: `http://localhost:8880/v1`）

接続できない場合は5秒で、接続後に応答がない場合は30秒で打ち切ります。

## Kokoro-FastAPI などのサーバの導入方法を教えてほしい

サーバの導入・動作は、PPVoice のサポート対象外です。各プロジェクトの案内を参照してください。→ [音声合成エンジン](engines.md#openai-互換エンジン)

## 「TTSサーバがエラーを返しました」と表示される

OpenAI互換のサーバが合成に失敗しています。ログに、サーバが返したメッセージと、読み上げようとした文が表示されます。

- **「Input contains no speakable text」（読み上げられる文字がない）:** 声の言語とノートの言語が合っているか確認してください。Kokoro-FastAPI の日本語の声（`jf_` / `jm_` で始まる声）では、サーバ側で日本語の処理（MeCab の辞書など）が使える必要があります
- 詳しい原因は、TTS サーバのログに出力されます。サーバの設定については、各プロジェクトの案内を参照してください

## 字幕が長すぎる

ノートを改行で区切ると、字幕も改行ごとに切り替わります。英語のように改行なしの段落で書いている場合は、「文末 (. ! ?) でも区切る」をオンにしてください。字幕の中だけで改行したい場合は `<br>` を使います。

## 読み方がおかしい

`{表示|読み}` で読みを指定できます。VOICEVOX では、アクセント（音の高低）も `{橋|はし|2}` のように指定できます。→ [ノートの書き方](notes.md#読み指定)

「リスト構造」が「リスと構造」のように聞こえるなど、複合語の区切りが不自然な場合は、`{リスト構造|リストこうぞう|4}` のように語全体に読みとアクセントを指定すると、1つの語として読みます。→ [複合語のアクセント](notes.md#複合語のアクセント)

## 数式が LaTeX の文字列のまま表示される

LaTeX の変換に失敗しています。生成時のログに警告と失敗した式が表示されるので、式の書き方を確認してください。数式は `{$...$|読み}` の形で、読みと一緒に書く必要があります。

## アニメーションのタイミングがずれる

文の途中に書いた `<next>` は、文字数の比率からタイミングを推定するため、少しずれることがあります。正確に合わせたい場合は、`<next>` を文の境界（改行の位置）に書いてください。→ [アニメーション連携](animation.md)

## 一部のスライドだけ作り直したい

上部の「スライド」で「一部」を選ぶと、生成するスライドを選べます。

なお、2回目以降の生成では、ノートや設定を変えていないスライドは前回の合成結果を使うので、すべてのスライドを生成しても速く終わります。

## 辞書を変えたのに読みが変わらない（キャッシュ）

PPVoice は、ノート・役・辞書・設定が同じスライドには、前回の合成結果を使います。VOICEVOX のユーザー辞書など、音声合成エンジン側の変更は検出できないため、そのような変更をしたときは「その他」タブの **キャッシュを削除** を押すか、「前回の合成結果を使う」をオフにしてください。コマンドラインでは `--no-cache` を付けます。

## 起動時にインターネットに接続している？

新しいバージョンがあるかを確かめるため、起動時に GitHub（`api.github.com`）に最新のリリースを問い合わせます。送るのは通常のリクエストだけです。「その他」タブの **起動時に新しいバージョンを確認する** でオフにできます。

## PowerPoint が勝手に起動した

動画の書き出し・字幕のプレビュー・スライドのサムネイルでは、PowerPoint を画面に出さずに使います。開くのは一時的なコピーで、PowerPoint で開いている資料には影響しません。PPVoice が PowerPoint を起動した場合は、使い終わると終了します。使いたくない場合は、「その他」タブの **PowerPoint と連携する** をオフにしてください。

## 不具合を見つけた

[GitHub の Issues](https://github.com/Yasuaki-Ito/PPVoice/issues) で報告してください。PPVoice のバージョン、発生した現象、再現手順（できれば問題が起きる PPTX のノートの内容）を書いていただけると調査が早くなります。
