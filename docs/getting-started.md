# はじめかた

## 必要なもの

- Windows（64bit）
- 音声合成エンジン（次のどちらか。PPVoice と同時に起動しておきます）
    - [VOICEVOX](https://voicevox.hiroshiba.jp/)（日本語）
    - Kokoro-FastAPI などの OpenAI 互換 TTS サーバ（英語など）→ [音声合成エンジン](engines.md#openai-互換エンジン)
- PowerPoint（ノートの作成、生成した PPTX のスライドショー再生に使います。PPVoice の生成処理自体は PowerPoint を使いませんが、PowerPoint があれば、動画の書き出し・字幕のプレビュー・スライドのサムネイルにも使います）

## インストール

[Releases](https://github.com/Yasuaki-Ito/PPVoice/releases/latest) から最新の `PPVoice-x.x.x-setup.exe` をダウンロードして実行してください。インストール後、スタートメニューまたはデスクトップの **PPVoice** から起動できます。

新しいバージョンは、インストーラを実行すればそのまま上書きインストールされます。新しいバージョンが公開されると、起動時にログでお知らせします（「その他」タブでオフにできます）。

## 表示言語

ログ欄の右上で、日本語と英語を切り替えられます。選んだ言語は次回の起動時にも使われます。初回の起動時は、Windows の表示言語に合わせます。

## 使い方

### 1. ノート欄に読み上げる文章を書く

PowerPoint で、スライド下部の「ノート」欄に読み上げたい文章を書きます。

```
今日は行列の固有値について説明します。
まず、簡単な例から見ていきましょう。
```

- 改行ごとに区切って合成され、字幕も改行ごとに切り替わります
- ノートが空のスライドは音声なしになります
- 読み方の指定や字幕の装飾などの書き方は [ノートの書き方](notes.md) を参照してください

### 2. 音声合成エンジンを起動する

VOICEVOX を使う場合は、VOICEVOX を起動しておきます。PPVoice は初期設定で `http://localhost:50021` に接続します。

### 3. PPVoice で生成する

1. 画面上部の **入力** に PPTX を指定します（ウィンドウへのドラッグ＆ドロップでも指定できます）。**出力** は自動で `元のファイル名_speech.pptx` になります
2. **音声** タブの「話者取得」を押し、**キャスト** で選んでいる役の話者とスタイルを選びます
3. 必要に応じて「テスト」欄の文章で **▶ 再生** を押し、声を確認します
4. **生成開始** を押します

生成した PPTX をスライドショーで再生すると、各スライドで音声が自動再生され、読み終わると次のスライドに進みます。PowerPoint があれば、生成の後に表示される **▶ スライドショーで確認** ですぐに再生できます。

### 4. （必要なら）動画にする

**動画も作る** をオンにして生成すると、PowerPoint で MP4 も書き出します。→ [動画への変換](video.md)

## 画面の構成

| 場所 | 内容 |
|---|---|
| 上部 | 入力・出力ファイル、生成するスライド（「一部」を選ぶと、サムネイルを見ながら選べます）、動画も作る、生成開始 |
| 音声タブ | 音声合成エンジン、キャスト（役の一覧と、選んだ役の話者・速度などの設定）、間、辞書、テスト再生 → [掛け合い](dialogue.md) |
| 字幕タブ | 字幕の表示・文字・装飾・位置・句読点、プレビュー → [字幕の設定](subtitles.md) |
| その他タブ | アニメーション、ノートの確認、設定の保存、キャッシュ、PowerPoint との連携、更新の確認 |
| 右側 | ログ、ドキュメントへのリンク、表示言語 |

## 音声の項目

| 項目 | 説明 |
|---|---|
| エンジン | VOICEVOX / OpenAI互換 (Kokoro等) を切り替えます |
| 話者・スタイル | 選んでいる役の声です（VOICEVOX ではキャラクターとスタイル、Kokoro では言語・性別と声） |
| 速度・音量 | 選んでいる役の読み上げ速度と音量です。ノートの `<speed>` `<volume>` で文ごとに変えられます |
| ピッチ・抑揚 | 声の高さと抑揚です（VOICEVOX のみ） |
| 間 (秒): 文 | 文と文の間に入れる無音の長さです |
| 間 (秒): 話者交代 | 話者が替わるときの無音の長さです（空欄なら「文」と同じ） |
| 間 (秒): 末尾 | 読み終わってから次のスライドに進むまでの時間です |
| 文末 (. ! ?) でも区切る | 改行がなくても、文末で区切って合成・字幕表示します（英語の段落向け） |
| 辞書... | 資料全体の読みを登録します → [ノートの書き方](notes.md#読みの辞書) |

役を1つしか使わない場合は、キャストに役が1つあるだけで、今までどおりに使えます。
