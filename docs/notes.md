# ノートの書き方

PPVoice は、スライドのノート欄に書かれた文章を読み上げます。ノートには、読み方の指定や字幕の装飾などを書き込めます。

## 文の区切り

- 改行ごとに1つの文として合成し、字幕も文ごとに切り替わります
- 文と文の間には「文の区切り (秒)」の無音が入ります
- 改行がなければ、ノート全体が1つの文になります（字幕も1つ）
- 「文末 (. ! ?) でも区切る」をオンにすると、改行がなくても `. ! ?` の後で区切ります。英語のように段落で書く場合に使います。`e.g.` `Dr.` `Fig.` などの略語、`J. Smith` のような頭文字、行頭の番号（`1.`）では区切りません

字幕の中だけで改行したい場合は `<br>` を使います（文は区切りません）。

```
これは1つ目の文です。
これは2つ目の文で、<br>字幕は2行になります。
```

## 読み指定

`{表示|読み}` と書くと、字幕には「表示」が、音声合成エンジンには「読み」が渡されます。

```
{PPTX|パワーポイント}ファイルを読み込みます。
```

- 字幕: PPTXファイルを読み込みます。
- 読み上げ: パワーポイントファイルを読み込みます。

`{` や `}` 単体は、`{...|...}` の形でなければそのまま表示されるため、エスケープは不要です。`{...}`（`|` なし）で囲んだ部分は、タグや句読点の置換の対象外になり、そのまま表示されます。

### アクセント指定（VOICEVOX のみ）

VOICEVOX の読み上げでアクセント（音の高低）が正しくない場合、3番目の値で修正できます。

```
{端|はし|0}を歩く。
{箸|はし|1}を持つ。
{橋|はし|2}を渡る。
```

番号は、声の高さが下がる位置を表します。「はし」（2文字）の場合は次のとおりです。

| 番号 | 高低パターン |
|---|---|
| `0` | は↗**し**（上がったまま） |
| `1` | **は**↘し |
| `2` | は↗**し**↘（後に続く助詞などで下がる） |

指定できる番号は `0` から読みの文字数までです（「きょ」「しゃ」などの拗音は1文字と数えます）。番号を `0` から順に変えてテスト再生し、自然に聞こえるものを選ぶのがおすすめです。

## 数式

読み指定の表示部分を `$...$` で囲むと、字幕に LaTeX の数式が表示されます（PowerPoint の数式として埋め込まれます）。数式の読みは自動では作られないため、`|` の後に読みを書いてください。

```
円の方程式は {$x^2+y^2=r^2$|エックスにじょうプラスワイにじょうイコールアールにじょう} です。
相加相乗平均は {$\frac{a+b}{2} \geq \sqrt{ab}$|にぶんのエープラスビーはルートエービーいじょう} です。
```

- 数式の中では `{` `}` `|` `<` `>` をそのまま使えます
- アクセント指定（`{$f(x)$|エフエックス|1}`）や `<color>` などの書式タグも組み合わせられます
- 数式の中の句読点は、句読点の置換の対象外です
- LaTeX の変換に失敗した場合は、LaTeX の文字列のまま表示されます（ログに警告が出ます）
- 数式は太字で表示されます（「数式を太字」でオフにできます）→ [字幕の設定](subtitles.md#文字装飾)

## 字幕の書式タグ

字幕の一部に装飾を付けられます。タグは読み上げには影響しません。大文字・小文字どちらでも書けます。

| タグ | 効果 |
|---|---|
| `<b>...</b>` | 太字 |
| `<i>...</i>` | 斜体 |
| `<u>...</u>` | 下線 |
| `<color=#RRGGBB>...</color>` | 文字色 |
| `<font=フォント名>...</font>` | フォント |
| `<size=N>...</size>` | 文字サイズ（絶対指定 `<size=24>`、相対指定 `<size=+4>` `<size=-2>`） |
| `<br>` | 字幕の中での改行 |

```
これは<color=#FF0000>重要な</color>ポイントです。
<b><u>注意事項</u></b>を確認してください。
```

`{<b>}` のように `{...}` で囲むと、タグとして解釈されずにそのまま表示されます。

## 音声の制御タグ

文ごとに読み上げ方を変えられます。タグを書いた文（行）全体に効きます。

| タグ | 効果 |
|---|---|
| `<speed=N>` | 読み上げ速度（`<speed=1.5>` で1.5倍速） |
| `<volume=N>` | 音量（初期値 1.0。`<volume=0.5>` で半分） |
| `<pitch=N>` | 声の高さ（`<pitch=0.1>` `<pitch=-0.05>` など。VOICEVOX のみ） |
| `<intonation=N>` | 抑揚（初期値 1.0。`<intonation=0.5>` で抑える。VOICEVOX のみ） |
| `<wait=N>` | 無音を入れる（`<wait=1s>` `<wait=500ms>`。単位なしは秒） |

```
<speed=1.3>この文は少し速く読みます。
ここで一息入れます。<wait=2s>
<volume=0.6>この文は小さめの声で読みます。
```

`<wait>` は文の途中にも書けます。その位置で文が区切られ、指定した長さの無音が入ります。
