# Subtitles

With **Show subtitles** on, subtitles are shown at the bottom of each slide in time with the narration. Each subtitle is added as a text box that appears and disappears sentence by sentence, so you can adjust their position or text in PowerPoint after generating.

## Style

| Style | Description |
|---|---|
| Outline | Adds an outline and a glow to the text. Each can be turned on or off, with its color and width/size |
| Background | Adds a semi-transparent background behind the subtitle, with its color and opacity |

## Text

| Setting | Description |
|---|---|
| Font size | Subtitle font size (pt) |
| Font | Subtitle font. Click **Select** to choose from the fonts installed on your PC |
| Bottom margin | Distance from the bottom of the slide (as a fraction of the slide height) |
| Text color | Subtitle text color |

## Text style

**Bold**, **Italic**, and **Underline** set the default style of all subtitles. The `<b>` `<i>` `<u>` tags in the notes are applied on top of it.

**Bold math** (default: on) shows math in subtitles in bold. PowerPoint draws equations in Cambria Math, and the font cannot be changed, so math may look thin next to a heavy subtitle font. This setting compensates for it.

## Replacing punctuation

You can replace the punctuation shown in subtitles. In **Replace**, choose what **Comma** (`、` `，` `,`) and **Period** (`。` `．` `.`) are replaced with. This is mainly for Japanese text.

- The narration is not affected
- Punctuation inside `{...}` and in math is not replaced
