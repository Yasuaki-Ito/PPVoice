# 字幕の設定

「字幕を表示する」をオンにすると、読み上げに合わせてスライドの下部に字幕を表示します。字幕は文ごとに表示・非表示が切り替わるテキストボックスとして追加されるので、生成後に PowerPoint で位置や文字を手直しすることもできます。

## スタイル

| スタイル | 説明 |
|---|---|
| 縁取り | 文字に輪郭とぼかし（光彩）を付けます。輪郭・ぼかしはそれぞれオン/オフ、色、太さ・サイズを設定できます |
| 背景付き | 字幕の後ろに半透明の背景を敷きます。背景色と不透明度を設定できます |

## 文字

| 項目 | 説明 |
|---|---|
| フォントサイズ | 字幕の文字サイズ（pt） |
| フォント | 字幕のフォント。PC にインストールされているフォントから選べます |
| 下マージン | スライドの下端から字幕までの距離（スライドの高さに対する割合） |
| 文字色 | 字幕の文字の色 |

## 文字装飾

「太字」「斜体」「下線」をオンにすると、字幕全体の標準のスタイルになります。ノートの `<b>` `<i>` `<u>` タグによる指定は、これに加えて適用されます。

**数式を太字**（初期値: オン）は、字幕の中の数式を太字で表示します。PowerPoint の数式は Cambria Math で描画され、フォントを変えられないため、太めの字幕フォントと並べると数式だけ細く見えるのを補います。

## 句読点の置換

字幕に表示する句読点を、別の文字に置き換えられます。「置換」で、読点（`、` `，` `,`）と句点（`。` `．` `.`）のそれぞれについて変換先を選びます。

- 例: 句点を「(全角空白)」にすると、字幕の「。」が空白になります
- 読み上げには影響しません
- `{...}` で囲んだ部分と数式の中の句読点は置換されません
