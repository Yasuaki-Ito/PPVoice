# 動画への変換

PPVoice で生成した音声付き PPTX は、動画（MP4）にできます。音声、字幕、アニメーション、スライドの切り替えのタイミングがそのまま動画になります。

## PPVoice から書き出す（PowerPoint が必要）

PowerPoint がインストールされていれば、PPVoice から直接書き出せます。

1. 上部の **動画も作る** をオンにする
2. **生成開始** を押す

音声付き PPTX を生成した後に、PowerPoint で `出力ファイル名.mp4` を書き出します。解像度は「その他」タブの **動画の解像度** で選べます（初期値は 1080p）。書き出しには、スライドの長さに応じて時間がかかります。

- PowerPoint で開くのは一時的なコピーです。PowerPoint で開いている資料には影響しません
- 生成の後に表示される **▶ スライドショーで確認** で、書き出す前にスライドショーで確認することもできます
- コマンドラインでは `ppvoice-cli generate 入力.pptx --video` で書き出せます → [CLI](cli.md)
- PowerPoint との連携は、「その他」タブの **PowerPoint と連携する** でオフにできます

## PowerPoint で書き出す

PowerPoint の標準機能でも変換できます。

1. 生成した PPTX を PowerPoint で開く
2. **ファイル → エクスポート → ビデオの作成** を選ぶ
3. 「記録されたタイミングとナレーションを使用する」を選ぶ
4. **ビデオの作成** を押す

!!! tip
    動画にする前に、スライドショーで一度再生して、音声・字幕・アニメーションのタイミングを確認しておくと安心です。
